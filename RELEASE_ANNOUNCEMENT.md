# EPS Live Viewer 3.1 — 从实时查看，到快速修改科研图

> 版本 3.1.0。

**1.0** 专注 EPS 浏览与实时刷新；**2.0** 扩展配色、比较、多页、导出和视频工具；**3.0** 增加可识别文字的轻量编辑，让科研绘图的小修改更直接。

## 本次亮点

- **更完整的工作区**：菜单在上、标签在下，Home 随时返回最近文件；Settings / Language 入口始终可辨认。
- **修复画布与旋转文字**：EPS 导出保留页面留白；明确定位的旋转文字、单位与上标片段可编辑，悬停显示输入光标。
- 换色、PDF/EPS/PS 导出默认加入工具栏；备用 DPI 统一设置，不再反复弹窗。

- **在图上改文字**：双击可识别文字直接输入，拖选局部字符修改字体、字号、颜色、粗斜体；整段可旋转。改动实时可见，无需反复“应用并预览”。
- **科研符号工具盒**：按分类挑选希腊字母、运算符和常用符号，识别文字列表默认隐藏。
- **真正的矢量另存为**：支持重新生成 EPS / PS / PDF，保留原文件。EPS 保存当前页，PS/PDF 保存全部页面。
- **更顺手的界面**：简约品牌首页、最近文件、图标工具栏；初始窗口适应屏幕，关闭最后一个标签回首页。
- **统一偏好设置**：按功能分类，保存后同步窗口与标签页；各文件的文字、旋转及配色改动仍然独立。
- 保留实时刷新、相邻图比较、颜色替换、多页浏览及视频/动图制作；不新增大型运行依赖或字体包。

**功能边界**：仅承诺编辑可识别的独立文字片段；局部样式不跨片段排版。已转曲、特殊编码或复杂结构可能不可编辑，不含 OCR 或通用矢量排版。部分旧版 Ghostscript 会把导出的新文字变成矢量轮廓，建议同时保留编辑后的 PDF。

# EPS Live Viewer 3.1 — From live viewing to quick scientific-label edits

> Version 3.1.0.

**1.0** focused on EPS viewing and live refresh. **2.0** added recoloring, comparison, multi-page workflows, export and animation tools. **3.0** introduces lightweight editing of recognizable text.

- Menus above tabs, persistent Home access, and a discoverable bilingual Settings / Language entry.
- Preserved EPS canvas/margins and editing support for explicitly positioned rotated labels, units and superscript fragments, with I-beam hover feedback.
- Recolor and PDF/EPS/PS toolbar shortcuts; fallback DPI is a preference, not a repeated prompt.

- **Edit on the page:** double-click recognizable text and type; select characters to change font, size, color, bold or italic styling. Rotate whole labels and see changes live.
- **Scientific symbol toolbox:** categorized grids for Greek letters, operators and common symbols; the recognized-text list is optional.
- **Vector Save As:** regenerate EPS / PS / PDF without overwriting the original. EPS exports the current page; PS/PDF retain all pages.
- **A clearer workspace:** branded Home with recent files, icon toolbar, screen-fitting startup size, and return to Home when the last document tab closes.
- **Unified preferences:** logically grouped settings synchronize across windows/tabs while document edits remain independent.
- Existing live refresh, comparison, recoloring, multi-page and animation workflows remain. No large runtime dependency or font pack is added.

**EPS Live Viewer supports lightweight editing of recognizable PostScript text objects.** Character styles work within a recognizable run, not across separate runs. Outlined or structurally complex text may be unsupported; this is not OCR or a general-purpose layout editor. Some older Ghostscript versions outline newly exported text, so retain an edited PDF for future revisions.
