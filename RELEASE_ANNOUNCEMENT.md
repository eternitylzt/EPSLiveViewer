# EPS Live Viewer 3.1.1

本次为界面与性能维护更新：修正 Home 图标与标签栏的对齐，优化文件关联启动和标签切换，减少重复初始化与内存占用。现有功能及文件格式保持不变。

This maintenance release aligns the Home icon with document tabs, improves file-association startup and tab switching, and reduces repeated initialization and memory use. Existing features and file formats are retained.

解压 Windows/Linux 包后运行；macOS 将 app 拖到 Applications。EPS/PS 仍需安装 Ghostscript。校验文件见 SHA256SUMS.txt。
