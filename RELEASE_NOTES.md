# EPS Live Viewer 2.0.0

## 中文

这是一次较大的图像处理与多页工作流更新：

- 新增页面左/右旋转，菜单和快捷工具栏均可操作；多页 EPS/PS 可分别记录每页方向。
- 新增反转颜色和最多 16 组颜色替换，支持 RGB、HEX、系统屏幕取色器及颜色容差。
- 新增直接打开 PNG/JPG，并支持相邻文件切换、自动刷新、旋转、反色、替色和导出。
- 多页 EPS/PS 导出 PNG 时，可选择当前页或全部页面；全部页面会写入新文件夹。
- 调整后的内容可另存为 PNG、PDF、PS、EPS。旋转和整体反色保持矢量输出；任意颜色替换会以所选 DPI 封装位图页面。
- 视频/动图现在将多页 EPS/PS 的每一页视为独立帧，可与其他 EPS/PS/PNG/JPG 混合，并应用每页旋转和颜色调整。
- 继续支持任意页面尺寸，无需纸张大小选项；未增加新的第三方图像或 PDF 依赖。
- 更新中英文帮助、README 和跨平台发布配置。

## English

This is a major image-processing and multi-page workflow update:

- Added page rotation to the Image menu and quick toolbar; each EPS/PS page can keep its own orientation.
- Added color inversion and up to 16 color replacements with RGB, HEX, system screen picker, and tolerance controls.
- Added direct PNG/JPG opening with neighboring-file navigation, live refresh, rotation, inversion, replacement, and export.
- Multi-page EPS/PS PNG export can save the current page or every page into a new folder.
- Adjusted content can be saved as PNG, PDF, PS, or EPS. Rotation and whole-page inversion remain vector-based; arbitrary color replacement uses raster-backed pages at the selected DPI.
- Video/GIF creation now treats every EPS/PS page as an independent frame, mixes it with other supported files, and applies per-page rotation and color adjustments.
- Arbitrary page sizes remain supported, so no paper-size setting was added. No new third-party image or PDF dependency was introduced.
- Updated bilingual help, documentation, and cross-platform release settings.
